Networking Fundamentals

LAN

A Local Area Network connects devices within a small area, such as a home, office or college.

WAN

A Wide Area Network connects networks over large geographical areas.

IP Address

An IP address identifies a device or network interface for communication using IP.

DNS

DNS helps translate domain names, such as example.com, into IP addresses.

DHCP

DHCP automatically provides devices with IP configuration, such as an IP address.

Subnet Mask

A subnet mask helps identify the network and host portions of an IPv4 address.

Network Devices

Router

A router forwards packets between different IP networks.

Switch

A network switch connects devices in a LAN and forwards Ethernet frames.

Server

A server provides services or resources to other computers on a network.

Access Point

A wireless access point allows Wi-Fi devices to connect to a network.

Network Topologies

Star Topology

All devices connect to a central device, usually a switch.

Bus Topology

Devices share a common communication backbone.

Mesh Topology

Devices have multiple interconnections, providing alternative communication paths.

Network Security

Firewall

A firewall filters network traffic according to configured security rules.

Access Control

Access control limits network resources to authorized users and devices.
