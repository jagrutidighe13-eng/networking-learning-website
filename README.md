# Networking Learning Hub

## About the Project
A beginner-friendly educational website about computer networking concepts.

## Topics Covered
- LAN and WAN
- IP addresses and subnet masks
- DNS and DHCP
- Routers, switches, servers and access points
- Star, bus and mesh topologies
- Firewalls and access control

## Technologies Used
- HTML5
- CSS3

## Features
- Navigation menu
- Networking topic cards
- Responsive layout
- Smooth navigation between sections

## How to Run
1. Download the repository.
2. Keep `index.html` and `style.css` in the same folder.
3. Open `index.html` in a web browser.

## Learning Outcomes
Practiced HTML page structure, CSS styling, CSS Grid, navigation links and responsive design.
